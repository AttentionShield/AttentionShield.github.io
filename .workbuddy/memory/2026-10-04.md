# 2026-10-04

## Hugo 极简博客站搭建

参考 https://lilianweng.github.io/archives/ 的单栏极简技术博客风格，从零搭建了本工作区的博客站。

### 技术选型

Hugo 0.167.0 Extended + PaperMod 主题（git submodule，默认分支是 `master` 不是 `main`）。
用户明确选择了 Hugo 方案（而非 Astro / 手写静态站），写作方式为本地 Markdown。

### 站点设计原则

内容优先于界面：白底、单栏、无卡片配图；文章元信息只有日期 + 阅读时长 + 标签；
归档页用「年 → 月 → 文章」两级分组；正文行高 1.95，版心 46rem。

### 关键实现

- `layouts/home.html` — 自定义首页模板，纯文字文章列表（主题默认是卡片式）
- `layouts/index.json` — 覆盖主题同名的搜索索引模板
- `layouts/_shortcodes/notice.html` — 提示块 shortcode（tip/note/warning）
- `assets/css/extended/reading.css` — 全部自定义样式，约 700 行

### 踩过的坑

1. **winget 装了 Hugo 但 Links 里是 0 字节坏链接** — cmd 敲 `hugo` 报「此应用无法在你电脑运行」。
   真实二进制在 `WinGet\Packages\Hugo.Hugo.Extended_..._8wekyb3d8bbwe\hugo.exe`（65MB）。
   解决：删掉 `WinGet\Links\hugo.exe`，把 Packages 目录写入用户 PATH。

2. **Hugo 0.167 模板查找规则变化** — 主题的 `layouts/index.json` 不再被首页 JSON 输出格式匹配，
   报 `Template /index.json is unused`，搜索索引不生成。
   解决：需在 `hugo.toml` 声明 `[outputFormats.JSON]`，并在 `content/_index.md` 里写 `outputs: [HTML, JSON]`，
   同时在项目层覆盖 `layouts/index.json`。

3. **`languageCode` 已在 Hugo 0.158 废弃** — 改用 `locale`，否则每次构建 WARN。

4. **中文 alert 语法块 `::: 提示` 不被解析** — 渲染成字面量文本。改用自建 shortcode。

5. **主题 html 上设了 `font-size: 18px`** — 放大所有 rem/em，需在 extended 层改回 16px 基准。

6. **PaperMod 硬编码了深色（catppuccin）语法高亮配色** — 浅色代码块上文字看不清，
   需用 `!important` 压过，chroma 的 token 类要逐个覆盖。

7. **PaperMod 无 `home.html` 模板** — Hugo 走默认逻辑导致首页出现头像区，必须自己写。

8. **file:// 预览丢样式** — Hugo 产物用绝对路径 `/assets/...`，且 SRI integrity 校验会失败。
   写了 `tools/preview.py` 生成相对路径副本并去掉 integrity。

### 验证方式

Chrome headless 截图：`--headless --disable-gpu --no-sandbox --screenshot=... --virtual-time-budget=9000`。
注意 Git Bash 起的服务 Chrome 原生进程访问不到，需用 file:// 协议配合 preview.py 生成的副本。

## 站点改名：薇薇 → MindSaver

用户把全站站名从「薇薇」改成「MindSaver」。

**踩坑**：批量替换把 `hugo.toml:90` 的 `homePostsCount = 0` 改成了 `homePostsCount = `
（`0` 被误删），报 `toml: unexpected character U+000A at start of value`。
教训：替换前先确认目标文本上下文，纯数字值容易被选中。

**顺带调整**（站名相关配置分散在多处，改一处不会全局生效）：
- `hugo.toml` → `title`（浏览器标签页标题）
- `hugo.toml` → `params.label.text`（导航栏左上角）
- `hugo.toml` → `params.homeInfoParams.Title`（首页大标题）
- `content/_index.md` → `title`
- `README.md` 首行标题
- `content/about.md` → 「关于我」段落原本是我写的占位文案，已清空留注释让用户自己填

站名统一为「MindSaver 的技术笔记」（中间带空格，中英文混排更易读）。
文章页标题格式确认为「文章名 | 站名」，与参考站一致。
